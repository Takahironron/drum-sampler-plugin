- 2026-11-02 時点: 3/3 で「同じキットに聞こえない」。切り出した音そのものの質（`kit_parts_audition.wav`）と、並べ直しの損失（`rerender_self.wav` との差）を分けて原因を見る。
- 2026-11-03 の切り分け（a01、a07）: `rerender_self.wav`（各打を自身の区間で鳴らし直し）は**良好**、`kit_parts_audition.wav`（切り出した一打一打）は**少し良好**。→ 疑似正解の打点と区間の切り方は問題なく、切り出した音も使える。問題は **3 層 × 3 音のキットへの並べ直し**（打ごとの音量を 3 段階に丸める、ラウンドロビンに別の奏法が混ざる、尾の長さが合わない）。
- 対策（2026-11-03 実装、合成音で確認）: B = 打ごとの音量合わせ ＋ 同じ種類の次の打で止めるチョーク（距離 0.75 → 0.72）。C = 特徴（音量・減衰・明るさ）の k-means で種類ごとに代表 12 音を残し、各打に最も近い音を選ぶ ＋ 音量合わせ ＋ チョーク（0.75 → 0.44。自己再現は 0.10）。実ステムでの聞き比べは次の実行で。
