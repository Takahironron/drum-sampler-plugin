## 判定と次の手

**結論: 続ける（Phase 1 へ進む）。ただし採譜は目安に届いていないので、Phase 1 の最初に下の 1 を置く。**

根拠:
- 仕様の中心「ステムからキットを組んで再現する」は、M0-2（9/10）と M0-3（全曲で低下）で成り立つことが確かめられた。
- 採譜（M0-1）は 0.77 で目安 0.85 に届かないが、差の大半はゴーストノート（velocity 40 未満）の取りこぼしで、キットの再現と MIDI の書き出しの用途では影響が限定的。Phase 1 には採譜の修正 UI がある。
- 計画書 7 章の変更順「(1) 採譜が弱い → 自前の合成データで学習し直す、分類の数を減らす」のうち、合成データの混ぜ込みは実施済み（電子キックに効いた）。分類は M0 の 3 種で測っているので減らせない。

Phase 1 に持ち越す課題（優先順）:
1. **採譜のハイハットとスネアの小さい打。** E-GMD の全 36,000 本で学習、ゴーストノートを別の目標に分ける（開閉・強さの段階）、公開モデル（ADTOF、madmom）との比較、区分 B（正解 MIDI 付きの実ステム）での測定。検証と test の差（0.87 対 0.77）の原因の特定。
2. **パート分けを自前で行う。** M0-2 は SpectraLayers のパート別ステムに依存した。計画書 3.3 の NMFD か、StemGMD で学習したモデルで代える。これが無いと製品の経路が成り立たない。
3. **打点で説明できない音の扱い。** タンバリン・シェイカー・残響（a01）。「その他のパーカッション」の種類を足すか、元 − 自己再現 の残差を「残差の層」として混ぜる。
4. **エフェクトの当てはめの範囲と初期値。** 今の固定チェーンは範囲の端に張り付く。コンプ・歪み・ゲートを足し、乾いた音の基準（内蔵ライブラリ、モーダル音）で再評価する。
5. **代表音の選び方の天井。** 候補を全部にしても距離が下がらないので、特徴の設計（低域の形、減衰の形）か、聞こえ方に沿った距離の指標が要る。STFT 距離はサンプル置き換えの評価には粗い。

Phase 0 で確かめた道具立て（Phase 1 に引き継ぐ）: Python の採点・切り出し・当てはめ（`analysis/`）、E-GMD での学習と ONNX 書き出し（`train_transcriber.py`）、JUCE の空のプラグインと CI（`plugin/`）、ライセンス一覧（VST3 SDK は MIT、JUCE Starter はスプラッシュ不要）。
