## 聞き比べ（Takahiro、`original_cut.wav` と `rerender_parts.wav`）

- 方式 A（2026-11-02）: a01・a07・a10 とも「同じキットに聞こえない」。

- 方式 C（2026-11-03）: **大幅に改善**。特に a07 と a10。a01 はまだ不自然。

## 読み取り

1. 数字と耳が一致した。A → C で距離は 7 曲とも下がり、聞いた印象も大きく良くなった。音量合わせだけ（B）は小さく、奏法の違いを残した代表音から各打に近い音を選ぶこと（C）が効いた。
2. a01（U2 の生ドラム）は C でも自己再現との差が大きい（1.81 対 0.23）。生ドラムは一打ごとの揺れ（部屋の響き、強さ、奏法）が大きく、12 音の代表では足りない可能性と、「同じ種類の次の打で止める」チョークが生ドラムの余韻を切っている可能性がある。チョークの方針（全部／ハイハットだけ／無し）を表に並べ、`--kit-size` と `--only a01` で試せるようにした。
3. 自己再現の距離が大きい曲（a08 1.08、a10 0.76、a04 0.62）は、疑似正解の取りこぼし（a08 のハイハットのロールは 50 ms の最小間隔でまとまる、a04 は密度が高い）と、a10 のパートの和が元に一致しないことが原因。これらは切り出しの方式ではなく、打点の側の限界。
4. M0-2 の判定（半数以上の曲で「同じキットに聞こえる」）にはまだ届いていないが、方向は見えた。残りの改善候補: 代表音の数（24〜48）、チョークの方針、シンバルの扱い（長い余韻の重なり）、ハイハットの開閉を別の種類として扱う（Phase 2 の細かい分類）。
