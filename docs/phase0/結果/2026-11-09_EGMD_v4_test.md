# 評価の結果（2026-11-09。E-GMD v4 の test）

## E-GMD test 分割（60 本 × 30 秒、種類別しきい値 kick 0.6 / snare 0.6 / hihat 0.8 / tom 0.5 / cymbal 0.7）

| 種類 | v2 F | v4 P | v4 R | v4 F |
|---|---|---|---|---|
| kick | 0.824 | 0.901 | 0.882 | **0.890** |
| snare | 0.771 | 0.868 | 0.735 | 0.788 |
| hihat | 0.612 | 0.781 | 0.575 | **0.642** |
| tom | 0.886 | 0.885 | 0.894 | 0.884 |
| cymbal | 0.465 | 0.832 | 0.787 | **0.800** |

**M0-1 = 0.773**（v2 0.736、検証では 0.846）。

しきい値の掃引（test、1 つのしきい値で）: hihat は 0.6 が最良（0.684）、kick 0.7（0.905）、snare 0.5（0.791）、cymbal 0.8（0.866）。test で選び直せば M0-1 ≈ 0.79。

誤りの内訳:
- hihat: 取りこぼし 1573（小さい打 894、大きい打 679；同時 784、単独 789）、誤検出 360（打点の無い所 255）。しきい値 0.8 で精度は上がったが再現率 0.58。
- snare: 取りこぼし 658（小さい打 478）、誤検出 148（無し 126）。
- cymbal: 誤検出 45（ハイハット上 34）。v2 の 423 から激減。

## 読み取り

1. 時間差分のチャンネルと種類別しきい値は効いた。キック 0.89、シンバル 0.80。
2. **残る壁はハイハットとスネアの小さい打**（ゴーストノート、足で閉じる音）。ハイハットの取りこぼしの 57%、スネアの 73% が velocity 40 未満。
3. 検証（0.846）と test（0.773）の差が開いた。原因は、検証 80 本で選んだしきい値（特にハイハット 0.8）が test に合わないことと、エポック間の揺れ（検証が 0.71〜0.85）。
4. キット別の極端な弱さ（Jazz 0.06、Big Room 0.07、各 1 本）は v2 から変わらない。本数が少なく確かめにくいが、ライドが主役のキットと電子系のキットは別の対策が要る可能性。

## v5 に向けた変更（実装済み）

- 重みの移動平均（EMA、減衰 0.999）で検証・書き出し。生の重みと EMA の両方を検証して良い方を残す（揺れを抑える）。
- GRU を 2 層（dropout 0.2）、隠れ層 160。
- ハイハットとスネアの正例の重みを 6 → 8（小さい打の再現率を上げる狙い）。
- 検証を 160 本に（しきい値の選択を安定させる）。

v5 を Phase 0 の採譜側の最後の学習とし、その test の数字で M0-1 を判定する。
