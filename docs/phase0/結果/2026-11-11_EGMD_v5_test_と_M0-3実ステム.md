# 評価の結果（2026-11-11。E-GMD v5 の test と、M0-3 の実ステム）

## E-GMD v5 の test（60 本 × 30 秒、種類別しきい値 kick 0.7 / snare 0.7 / hihat 0.8 / tom 0.6 / cymbal 0.6）

| 種類 | v4 F | v5 P | v5 R | v5 F |
|---|---|---|---|---|
| kick | 0.890 | 0.898 | 0.888 | 0.888 |
| snare | 0.788 | 0.875 | 0.743 | 0.793 |
| hihat | 0.642 | 0.758 | 0.596 | 0.637 |
| tom | 0.884 | 0.934 | 0.947 | **0.935** |
| cymbal | 0.800 | 0.923 | 0.881 | **0.891** |

**M0-1 = 0.773**（v4 と同じ。検証は 0.868）。しきい値を test で選び直しても 0.78 前後。

- 検証（0.868）の伸びが test に移らなかった。validation と test で録音・キットの分布が違うか、160 本でもしきい値の選択が偏る。
- ハイハットの取りこぼし 1105 のうち小さい打 612（55%）、スネアの 625 のうち 452（72%）。**この構成とデータでは 0.77〜0.78 が頭打ち**で、残りはゴーストノートの問題。
- キット別で Jazz（0.07）と Big Room（0.07）は v2 から変わらず極端に悪い（各 1 本）。
- 判定の補助として、`eval_egmd.py --min-velocity 40` で velocity 40 未満の打を除いた F 値を出せるようにした（次の実行で）。

- **10 曲すべてで距離が下がり、平均で −33%。** M0-3 の「当てはめ前より明確に下がる」は満たす。
- ただしパラメータが範囲の端（gain −24、high −18、peak ±18）に張り付く曲が多い。合成の汎用キットが元から遠すぎる（明るすぎる）ことと、チェーンの範囲が狭いことを示す。製品では乾いた音の基準が内蔵ライブラリ（候補 (b)）かモーダル音（(c)）になるので、そこで再評価する。コンプ・歪み・ゲートはまだ無い。
- rt60 が 3.00 s（上限）や 0.06 s（下限）に付く曲は、リバーブの当てはめが EQ の肩代わりをしている可能性がある。
