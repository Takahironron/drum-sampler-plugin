## 読み取り

- **キックは NMFD で十分に分かれる**（平均 +11.5 dB。a09・a02 は +20 dB）。スネアは +2〜8 dB で、ハイハットは 0 dB 前後、シンバルはたいてい負。合成音での結果（スネア 19 dB、ハイハット 50 dB）より大きく低い。
- SNR が悪い主な原因は、**分離そのものより初期値にした打点**。v5 の打点は疑似正解に対して M0-1 0.555 で、取りこぼし（キック 399 → 117 など、正解の 1/3 しか拾わない曲がある）が多い。NMFD は打点の無い時刻の活性を抑えるので、拾えなかった打の音は残差（にじみ・残響を吸う成分）に落ちる。「パートの和 vs 元」（残差を除いた和）が 2.8 と大きいのはそのため（a08 1.2、a10 1.8 は残差が少ない）。
- a10 のスネア −15.3 dB、a06 の −1.3 dB は、スネアの打点を半分以下しか拾えていない曲（a10: 112 → 42、a06: 212 → 95）。
- 再現の距離は、方式 C 3.72・自己再現 3.21 で、SpectraLayers のパートからの 1.29・0.20 より大きい。**差の大半は自己再現の段階で付いている**（自己再現 0.20 → 3.21。方式 C はそこから +0.5 で、SpectraLayers の経路の +1.1 より小さい）。自己再現は打点と区間の切り方だけの損失なので、採譜の打点の取りこぼしが、そのまま製品の経路の天井になっている。
- それでも聞き比べでは「分離は良好」。SNR の数字は取りこぼした打がパートに無いことを強く罰するが、鳴っている音の質は保たれている。

## 結論と次の手

1. **パート分けは NMFD で足りる見込み**（Phase 1 の持ち越し 2）。学習モデル（StemGMD）は今は要らない。シンバルは当面サンプル・チョーク無しなので、SNR が負でも再現への影響は小さい（損失の内訳 cy −0.1 前後）。
2. **製品の経路の律速は、実ステムでの採譜の取りこぼし**（持ち越し 1 と同じ）。E-GMD で学習したモデルが CD 曲のステムに合っていない（検証 0.868 → 実ステム 0.555）。
3. 切り分けのために `run_eval.py` に 2 つ足した（次の実行で）:
   - `--parts nmfd-oracle`: 疑似正解の打点を初期値にして NMFD を動かす（NMFD の上限。分離の質だけを見る）。合成音の確認では、残差ありで自己再現 2.47・パートの和 1.29、残差なしで 1.54・0.00。
   - `--nmfd-no-residual`: 残差の成分を使わず、パートの和が元に等しくなるようにする（取りこぼした打の音も最も近いパートに入る。にじみも入る）。
4. 採譜を実ステムに合わせる手として、**疑似ラベルでの微調整**（v5 の重みを初期値に、区分 A の 9 曲の疑似正解で短く学習し、残り 1 曲で測る leave-one-out）を `train_transcriber.py --finetune-stems` に実装した（`E-GMD学習の手順.md` 5 節）。CD 曲のステムで学習したモデルは評価用に限る（R3）。
