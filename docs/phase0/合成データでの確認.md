# 合成データでの道具立ての確認（2026-10-23）

評価用ステムが揃う前に、`analysis/drumeval/synth.py` の合成音で「採点 → 採譜 → 切り出し → 当てはめ → 学習 → ONNX」の各道具が通ることを確かめた記録。**実曲の精度の主張ではない。** 数字は合成音に対するもので、M0 の判定には使わない。

| 道具 | 確認したこと | 数字（合成音） |
|---|---|---|
| 採点（F 値、STFT 距離） | 完全一致で 1、±50 ms の外で 0、EQ を変えると距離が増える | `analysis/tests/test_metrics.py` |
| 基準値の採譜（学習無し） | きれいな合成音で kick/snare/hihat を拾える | F = 1.0（にじみ 0.3 で kick 0.59、snare 0.56、hihat 1.0） |
| 切り出し → 層 → 再生 | 組み直したキットが、種類を入れ替えたものより元に近い | 元 vs 再現の STFT 距離が入れ替えの 1/2 未満 |
| エフェクトの当てはめ | 既知のゲイン・EQ・リバーブを掛けた目標に対して距離が明確に下がる | 4.84 → 0.21（初期値 2.76）。RT60 0.6 → 0.51、ローシェルフ -6 → -5.97 dB |
| 学習 → ONNX → ONNX Runtime | PyTorch と ONNX Runtime の出力が一致、ORT の推定で F 値が出る | 最大差 1e-5 未満。F 値は下記 |

## 分かったこと・直すべきこと

- 基準値の採譜は、スネアの打で高域も立ち上がるため「ハイハット」も同時に出す。切り出しではその打が「重なり」扱いになり、スネアが切り出せない。学習モデルで直す。
- 切り出しの「重ならない打」の条件（前 0.1 秒・後 0.15 秒）は、8分のハイハットが鳴り続ける曲では多くの打を落とす。実ステムでは NMFD（計画書 3.3）での分解が必要になる可能性が高い。
- エフェクトの当てはめは Powell 法で約 400 回の評価（5 秒の音で 10 秒程度）。実ステムで「乾いた音」が無い問題は計画書 3.5 の手順 1 のとおり、ライブラリ音か再現音を基準にする。
