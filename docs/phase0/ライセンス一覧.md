# Phase 0: データセット・モデル・ライブラリのライセンス一覧

作成日: 2026-10-23（各項目の確認日も同日）

## 目的

開発計画（`docs/plan/ドラム音源プラグイン開発計画.md`）と `CLAUDE.md` に出てくるデータセット・学習済みモデル・ライブラリ・SDK について、一次資料（公式リポジトリの LICENSE、公式ページ、公式フォーラム）で条件を確かめ、次の3つに振り分ける。

- **製品に組み込み可**: 販売する VST3 に同梱・リンクしてよい種類のライセンス（条件付きのものは条件を書く）。
- **学習にだけ使える・派生モデルの扱いに注意**: データそのものは製品に入れないが、学習に使える。学習したモデルを製品に入れてよいかは別途判断が要る。
- **評価・研究にだけ使う**: 非商用の条項がある。Phase 0 の精度測定や比較の基準にだけ使い、製品の処理経路には入れない。
- **要確認**: 一次資料で確かめられなかった、または一次資料どうしが食い違う。

## 注意

- これはライセンスの**種類の整理**であって、法的な判断ではない。販売前に、少なくとも JUCE・VST 3 SDK・製品に入れる学習済みモデルについては専門家に確認する。
- 「確認日」の時点の内容。JUCE と Steinberg は 2024〜2025 年に条件を変えており、今後も変わりうる。
- 引用は原文のまま（英語）。要約した箇所は「要約」と書く。
- データセットのライセンスと、そのデータで学習した**モデル**のライセンスは別物として扱う。CC BY 4.0 のデータで学習したモデルが自動的に CC BY になるわけではないし、非商用データで学習したモデルを製品に入れてよいかは、各データの条項と判例のない領域なので、本書では「注意」と書くにとどめる。

## 各項目の詳細

### 1. E-GMD (Expanded Groove MIDI Dataset)

- **何か**: Groove MIDI Dataset の演奏を Roland TD-17 の 43 キットで再録した、約 444 時間の音声＋MIDI。強さ（velocity）付きの採譜データセット。
- **ライセンス**: CC BY 4.0。公式ページの原文:
  > "The dataset is made available by Google LLC under a Creative Commons Attribution 4.0 International (CC BY 4.0) License."
- **出典**: https://magenta.tensorflow.org/datasets/e-gmd （確認日 2026-10-23）
- **読み**: 商用利用を妨げる条項は無い。学習に使える。
- **注意**:
  - 表示義務: 論文（Callender, Hawthorne, Engel, 2020, arXiv:2004.00188）の引用と、使った版の明記を求めている（"Please also make sure to specify which version of the dataset you are using."）。製品のクレジット欄に書く。
  - データ自体を製品に同梱する（例: 内蔵ライブラリに E-GMD の一打を切り出して入れる）場合も CC BY で可能だが、「電子ドラムの音色」なので内蔵キットの音としては魅力が薄い。主用途は採譜モデルの学習。
  - 学習したモデルが CC BY の「翻案」に当たるかは明確でない。安全側に倒すなら、製品のクレジットに E-GMD を書いておく。

### 2. Groove MIDI Dataset (GMD)

- **何か**: 10 人のドラマーの演奏 13.6 時間（MIDI 1,150 本、合成音声つき）。ジャンル・テンポ・分割のメタデータあり。
- **ライセンス**: CC BY 4.0。原文:
  > "The dataset is made available by Google LLC under a Creative Commons Attribution 4.0 International (CC BY 4.0) License."
- **出典**: https://magenta.tensorflow.org/datasets/groove （確認日 2026-10-23）
- **読み**: E-GMD と同じ。採譜の学習のほか、Phase 3 の「展開の生成」のルール作りや、Phase 5 の学習モデルの素材として使える。
- **注意**: 論文（Gillick et al., ICML 2019）の引用を求めている。MIDI パターンを製品の「基準パターン」として同梱するなら CC BY の表示が要る。

### 3. ADTOF（データセットと、コード・学習済みモデル）

#### 3a. データセット

- **何か**: リズムゲームの譜面（Rhythm Gaming World などのクラウドソース）と市販曲の音声から作った、359 時間の採譜ラベル付きデータ。配布物は音声ではなくメルスペクトログラム。
- **ライセンス**: Zenodo の記録に明示のライセンス欄は無く、「Conditions of use」に次の記述（要約: 内部の非商用利用のみ、再配布・改変・分解の禁止、入手は申請制）:
  > "offered free of charge for internal non-commercial use" / "Do not redistribute, modify, or disassemble the datasets."
  - Zenodo の記録は「Restricted」（"The record is publicly accessible, but files are restricted."）。README でも "available upon request on Zenodo"。
- **出典**: https://zenodo.org/doi/10.5281/zenodo.10084510 、 https://github.com/MZehren/ADTOF （確認日 2026-10-23）
- **読み**: **評価・研究にだけ使う**。市販曲由来なので、音声自体は配布されていない（スペクトログラムのみ）し、非商用の条件が付く。
- **注意**:
  - 自分で作り直す経路（`automaticGrooming.py` と譜面）についても、README は "we are not affiliated with Rhythm Gaming World and we do not control any material, possibly copyrighted, linked there." と断っている。譜面と音声の権利は各自の責任。
  - このデータで学習したモデルを製品に入れるのは、データの「internal non-commercial use」条件に反する読みが自然。製品用モデルの学習には使わない。

#### 3b. コードと学習済みモデル

- **ライセンス**: CC BY-NC-SA 4.0。README の原文:
  > "The content of this repository is licensed under a Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International License."
  - LICENSE ファイルの先頭: "Attribution-NonCommercial-ShareAlike 4.0 International"
  - NonCommercial の定義（CC 4.0 1(k)）: "NonCommercial means not primarily intended for or directed towards commercial advantage or monetary compensation."
- **出典**: https://github.com/MZehren/ADTOF/blob/master/LICENSE （確認日 2026-10-23）
- **読み**: **評価・研究にだけ使う**。学習済みモデルもコードも同じ非商用条件。Phase 0 の採譜精度の比較対象（ベースライン）として使うのはよいが、製品の採譜モデルにはしない。コードも読んで仕組みを学ぶにとどめ、コピーしない（CC BY-NC-SA はソフトウェア向けのライセンスではなく、コードに適用するのは CC 自身が推奨していない点も、判断を曖昧にする）。

### 4. StemGMD と LarsNet

#### 4a. StemGMD（データセット）

- **何か**: GMD の MIDI を Logic Pro X の 10 種のアコースティックキットで鳴らした、9 パート別のドラムステム。約 1,224 時間、展開後 1.13 TB。Zenodo の 2 つの記録に分割。
- **ライセンス**: CC BY 4.0。Zenodo の License 欄: "Creative Commons Attribution 4.0 International"。LarsNet README の原文:
  > "StemGMD is freely available on Zenodo under the CC-BY 4.0 license."
- **出典**: https://zenodo.org/records/7860223 、 https://github.com/polimi-ispl/larsnet （確認日 2026-10-23）
- **読み**: 学習に使える。パート分け（解析③）や、強さ別の層の学習データに向く。
- **注意**:
  - 引用を求めている（Mezza, Giampiccolo, Bernardini, Sarti, "Toward Deep Drum Source Separation," Pattern Recognition Letters, 2024）。
  - 音源は Logic Pro X のサンプルを鳴らしたもの。Logic の音を切り出して**製品の内蔵ライブラリに入れる**のは、Apple のサンプルライセンスが別に絡むので避ける（データの CC BY とは別の問題）。学習データとして使う分には配布者が CC BY で出しているものをそのまま使う。
  - Hugging Face にミラー（schismaudio/stemgmd）があるが、著者表記やハイハットの扱いが本家と違うとの指摘があるので、Zenodo の本家を使う。

#### 4b. LarsNet 学習済みモデル

- **ライセンス**: CC BY-NC 4.0。README の原文:
  > "Pretrained LarsNet model checkpoints can be found here (562 MB) licensed under CC BY-NC 4.0."
- **出典**: https://github.com/polimi-ispl/larsnet （確認日 2026-10-23）
- **読み**: **評価・研究にだけ使う**。パート分けの精度の比較対象にはよいが、製品には入れない。製品用のパート分けモデルは StemGMD（CC BY）から自分で学習する。

#### 4c. LarsNet コード

- **ライセンス**: **要確認**。GitHub のページに LICENSE の表示が無く、`raw.githubusercontent.com/polimi-ispl/larsnet/main/LICENSE` は 404（2026-10-23）。README にもコードのライセンス記述は無い（モデルとデータについてのみ記述）。
- **読み**: ライセンス表示の無いコードは、著作権法上は利用許諾が無い状態。読んで学ぶにとどめ、コピーしない。必要なら著者に問い合わせる。ISMIR 2023 LBD の "LARS: An open-source VST3 plug-in" が別リポジトリで出ている可能性があるが、未確認。

### 5. Demucs

#### 5a. コード

- **ライセンス**: MIT。LICENSE の先頭: "MIT License / Copyright (c) Meta Platforms, Inc. and affiliates." README: "Demucs is released under the MIT license as found in the LICENSE file."
- **出典**: https://github.com/facebookresearch/demucs （確認日 2026-10-23）
- **読み**: 製品に組み込み可（MIT の表示義務のみ）。

#### 5b. 学習済み重み（htdemucs, htdemucs_ft, hdemucs_mmi, mdx, mdx_extra など）

- **ライセンス**: **明示の付与が無い**。README は学習データを書くだけ（"It has been trained on the MUSDB HQ dataset + an extra training dataset of 800 songs."）で、重みのライセンスには触れない。作者（adefossez）の GitHub での回答:
  - Issue #327 "License of pre-trained models"（2022-05-23）:
    > "The model weights are not covered by the MIT license, and are provided only for scientific purposes."
  - Issue #508 "Include Models in commercial products?"（2023-08-02）:
    > "Weights are provided for research purpose!"
  - 学習データ MUSDB18-HQ の Zenodo 記録（https://zenodo.org/records/3338373 ）は License 欄 "Other (Non-Commercial)"、Notes に "provided for educational purposes only" / "should not be used for any commercial purpose without the express permission of the copyright holders."（46 曲 CC BY-NC-SA 4.0、2 曲 CC BY-NC-SA 3.0）。
  - 一方、Hugging Face の adefossez/HTDemucs には `license: mit` のタグが付いており、それが意図的かを問う discussion（https://huggingface.co/adefossez/HTDemucs/discussions/1 ）に作者の返答は無い（2026-10-23 時点）。
- **出典**: https://github.com/facebookresearch/demucs/issues/327 、 https://github.com/facebookresearch/demucs/issues/508 、 https://huggingface.co/adefossez/HTDemucs/discussions/1 （確認日 2026-10-23）
- **読み**: **評価・研究にだけ使う**（要確認を含む）。作者の明示の回答が「研究目的のみ」であり、学習データも非商用なので、製品に重みを同梱したり、製品のサーバーで動かしたりはしない。
- **注意**:
  - 本プラグインは「ドラムのステムを読み込む」仕様なので、Demucs は**ユーザーが各自で**ステムを作る手段の一つにすぎず、製品に Demucs を内蔵する必要はない。Phase 0 で「分離の道具を変えたステム」を作るときに使うのは問題ない（評価用ステムはリポジトリに入れない）。
  - 製品に分離機能を入れたくなった場合は、別の重み（自分で学習、または商用許諾のあるもの）が要る。

- **ライセンス**: MIT。LICENSE: "MIT License / Copyright (c) Microsoft Corporation." "Permission is hereby granted, free of charge, to any person obtaining a copy ..."
- **出典**: https://github.com/microsoft/onnxruntime/blob/main/LICENSE （確認日 2026-10-23）
- **読み**: 製品に組み込み可。

### 製品の処理経路に入れてよいもの（現時点の読み）

- JUCE 8（Starter → 売上に応じて Indie）、VST 3 SDK 3.8 以降（MIT）、ONNX Runtime（CPU、MIT）、STK（MIT 形式）、Mutable Instruments の STM32F 系コード（MIT、名称は使わない）、Demucs のコード（MIT、ただし製品に分離機能を入れない前提では不要）。

- Python の試作用: dasp-pytorch、auraloss（Apache-2.0）。C++ に移植する場合は表示を付ける。

### 評価・比較にだけ使うもの（製品には入れない）

- ADTOF（データ、コード、学習済みモデル）: 採譜のベースライン。
- LarsNet の学習済みモデル（CC BY-NC 4.0）: パート分けのベースライン。

- Magenta の E-GMD チェックポイント: 採譜のベースライン（ライセンスは要確認だが、評価に使う分には問題ない）。
